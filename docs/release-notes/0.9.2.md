# TEKSO Preview 0.9.2

[Български](../bg/release-notes/0.9.2.md) · [Docs index](../README.md) · [Previous: 0.9.1](0.9.1.md)

### What's new

- **Forms menu ("Forms" / "Бланки").** A separate menu for forms, with categories, search, favorites, a preview before you create a document, and "My forms" (view, open as a new document, rename without overwriting, delete). Claude gets 4 new tools for the forms. The library has 12 forms (7 Bulgarian, 5 English). All 12 are still drafts and have not been checked against the official sources.
- **Form language filter and a warning in "My forms".** You can show built-in forms in Bulgarian, English or both. "Save current document as my form" now warns that everything written in the document, including personal data, is saved with it.
- **Restart button after changing the language.** Settings now offers "Restart". It asks about unsaved documents first.
- **Signature stamp.** You can choose a stamp design (50 designs) or add your own stamp. A new "Signature details" dialog shows what is being signed.
- **Signatures panel and simpler sign dialog.** The signing windows were reworked.
- **Compact tools option for the Claude Desktop package.** Setting `TEKSO_MCP_TOOLSET` to `core` gives a smaller tool list (47 tools instead of 431; the published 0.9.1 has 427). The default is still the full list.

### Fixed

- **Changes that were not marked as unsaved.** TEKSO could close a document without asking after: undo or redo in a spreadsheet; changes made by Claude to a spreadsheet, presentation, PDF, or a text or publication in another tab; and new documents made from a template, a tool or a PDF operation. These are now marked as unsaved. Saving a presentation clears the mark.
- **Quit from the Dock or shutdown.** These two exits do not ask about unsaved changes. TEKSO now saves a last recovery copy, even when recovery copies are turned off, and offers it at the next start.
- **Recovery and Claude.** When Claude saves a document to its own file, the old recovery copy is removed. Recovery copies of documents opened by Claude now remember the file. A copy is also kept after "Restore a version", and when a document changes while it is being saved.
- **The same file in two tabs.** Opening a file again through a different path, such as a symbolic link, now switches to the tab that is already open.
- **Copies left behind by printing.** Earlier versions could leave a PDF copy of your document in the temporary folder after printing. On Mac it is now deleted right after printing. On Windows it is deleted later, once no program holds it open. Old copies are cleaned up at start.
- **Speaker notes during a slide show.** Pressing N no longer lays the notes over the slide: the slide shrinks to fit above them, and the Back, Next and Exit buttons stay on top of the notes strip.
- **Passwords through the script tool.** A password chosen by the model could get past the password check through `text_script`. Every step of a script is now checked before the first one runs, and the log hides passwords.
- **Signing windows.** Fixed content cut off at the edges, overflow, a locked PIN field and the certificate list. The PIN field is cleared when you change the certificate or search for cards again.
- **Keyboard shortcuts with a Cyrillic layout.** Letter keys, for example B, N, L, P and E during a slide show, now work when the keyboard is set to Bulgarian.
- **Small fixes from our own testing.** Labels and translations, the restart button, styles, footnotes, drafts, recovery and books created by the assistant.

### Changed

- **Signing labels no longer say "QES" or "КЕП".** The new label is "Sign with a card or key file…".
- **AI wording.** The texts about AI in the app, the README, EULA section 6.3, the documentation and the website describe more accurately what the AI can do.
- **Shorter tool list for AI clients.** Tools are no longer described twice (in Bulgarian and English), and seven descriptions are shorter.

### Known issues

- **Before you update from 0.9.1:** the update runs inside the old version, so these fixes do not protect it. Open every tab and press Cmd+S (Ctrl+S on Windows), including tabs that look saved. Do not let Claude work on documents while updating. Keep "Keep a recovery copy" turned on.
- **Unsaved work, what is still missing.** A document that Claude creates without a tab in the window is not asked about. After Claude saves a document itself, TEKSO may still ask you to save it. A presentation or PDF changed by Claude may not refresh on screen right away.
- **Limits of the recovery copy.** Books (`.obook`) get no recovery copy. Text still being typed in a cell is not kept. A newer copy of the same file replaces the older one.
- **Form drafts are not encrypted.** Drafts are kept in the app's local storage without encryption and may contain personal data.
- **Older limits**: `.numbers`, `.key` and `.mp4` are not read; Windows printing has no page ranges, duplex, grayscale or percent scaling; PDF/A, PDF/UA and PDF/X checks are simplified.

### How this build was checked

Automated tests, and an install, start and uninstall test on one Windows 11 computer. Most of the changes above have not been tried by hand on Windows, and updating from 0.9.1 and signing with a real card have not been tried with this build. TEKSO is still a preview and is not code signed.

# TEKSO Preview 0.9.1

[Български](../bg/release-notes/0.9.1.md) · [Docs index](../README.md) · [Previous: 0.9.0 beta 2](0.9.0-beta.2.md)

A preview version. Free during the preview and beta period.

## Highlights

- **Updates from the app.** At start TEKSO can ask GitHub whether there is a newer version and download it. Nothing is installed without your click, and your documents are saved first. You can turn the check off. See [Privacy](../privacy.md).
- **Text.** A new serif template for new documents, bundled fonts with Cyrillic, a font box with a live preview, and a document language setting.
- **Columns.** A menu with thumbnails and ready layouts, your own layouts, draggable column handles and a ruler, with a preview before you apply.
- **First start.** A new home screen, a short introduction and an example document with a proposed change.
- **Easier to use.** Stronger contrast, larger small text and targets, visible focus, error messages in plain words, and buttons in dialogs that say what they do.
- **OCR for scans.** An editable mode that writes visible text in a similar font, and conversion of a scan to Word or OpenDocument text.
- **Spreadsheets.** Errors shown where they happen, a clearer status bar and filter, automatic alignment, more DAX functions, and an indicator while a large file opens.
- **Presentations and documents.** More SmartArt layouts are drawn (pyramid, matrix, Venn, target, linked list, chevrons).

## Fixes

- Closing the window or quitting now asks about unsaved documents.
- A document stays marked as unsaved after you accept or reject proposed changes.
- A proposed replacement is shown and decided as one change.
- The word count no longer carries over from the previous document.
- Layout notes are shown in English.
- Large files no longer freeze the window while they are read.
- On macOS the AI connector no longer keeps growing in memory when documents are opened and closed repeatedly.

## Downloads

- `TEKSO_0.9.1_aarch64.dmg`: macOS (Apple Silicon)
- `TEKSO_0.9.1_x64-setup.exe`: Windows (64-bit)
- `tekso-macos.mcpb`, `tekso-win32.mcpb`: the TEKSO connector for Claude Desktop
- `SHA256SUMS.txt`: checksums

**The installers are not code-signed**, so macOS and Windows ask before the first start. See [Install](../install.md). The updater has its own signature check for downloaded updates; that is not a code signature from Apple or Microsoft.

If you have 0.9.0 beta 1 or beta 2, download this version once by hand. Those versions cannot update themselves.

## Known issues

- Updating from inside the app has not been tried on Windows.
- Quitting from the Dock or shutting down the computer does not ask about unsaved documents; they are kept for recovery.
- OCR accuracy was measured on synthetic pages only, not on real scans, and large scans can use a lot of memory.
- Apple formats are read, not written.
- New features have not all been checked by hand in Word, Excel, PowerPoint and Acrobat. Complex files may look different. Keep backups.
- No Intel Mac build yet.
- No real-time collaboration, no macros, no live multi-monitor presenting.
- No screen-reader support yet.
